My Cloud Support Lab

A hands-on AWS environment where I deployed a responsive static website on EC2, configured VPC networking and IAM-based S3 access, and added CloudWatch monitoring with SNS email alerts.

  • Launched a t3.micro EC2 instance using Amazon Linux 2023 and hosted the website with Apache.
  • Configured a public subnet, Internet Gateway, route table, and security group with HTTP access and SSH restricted to my IP.
  • Attached an EC2 IAM role with scoped permissions and tested S3 object upload and download in the ec2-backups/ prefix.
  • Worked across regions: EC2 in eu-north-1 and the S3 bucket in ap-south-1.
  • Created a CloudWatch dashboard and CPU alarm for average utilization above 80%, with an SNS email notification action.
  • Documented configuration, security choices, troubleshooting, screenshots, and the project architecture.
